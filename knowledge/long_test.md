# Python 学习笔记（超长版）
这是一段超长文本，专门用来测试分块功能。

## 第一部分：基础语法
Python 是一门优雅而简洁的语言。
变量定义不需要声明类型。
支持整数、浮点数、字符串、布尔值。
循环支持 for 和 while。
条件判断使用 if elif else。
列表、元组、字典、集合是最常用的数据结构。
函数使用 def 关键字定义。
支持默认参数、关键字参数。
支持匿名函数 lambda。
支持装饰器，用于增强函数功能。
支持面向对象编程，类使用 class 定义。
支持继承、多态、封装。
支持异常处理 try except finally。

## 第二部分：文件操作
Python 可以轻松读写文本文件。
使用 open 函数打开文件。
with 语句可以自动关闭文件，避免资源泄漏。
支持读取、写入、追加模式。
支持 csv、json、excel 等多种格式。
os 模块可以操作文件路径。
shutil 模块可以复制、移动、删除文件。

## 第三部分：数据处理
Python 在数据分析领域非常强大。
pandas 是最常用的数据处理库。
numpy 提供数值计算能力。
matplotlib 用于绘图。
数据清洗、数据转换、数据统计都非常方便。
可以轻松处理百万级数据。

## 第四部分：Web 开发
Python 有很多优秀的 Web 框架。
FastAPI 是现代、快速的 Web 框架。
Flask 轻量灵活。
Django 功能全面。
支持 RESTful API。
支持 WebSocket。
支持异步请求。

## 第五部分：自动化与爬虫
Python 可以轻松实现自动化。
requests 用于发送 HTTP 请求。
BeautifulSoup 用于解析网页。
Selenium 用于模拟浏览器。
可以自动办公、自动爬取数据、自动发送邮件。

## 第六部分：【文档后半部分关键内容】
### 重点知识：异步编程
Python 3.7+ 支持 asyncio 异步编程。
async 定义异步函数。
await 调用异步任务。
异步可以极大提高 IO 密集型任务的效率。
常用于爬虫、API 服务、批量处理任务。

### 重点知识：并发与多线程
Python 提供 threading 模块。
多进程适合 CPU 密集型任务。
多线程适合 IO 密集型任务。
线程池可以简化开发。
 concurrent.futures 提供高级接口。

### 重点知识：性能优化
使用局部变量比全局变量更快。
避免不必要的循环嵌套。
使用生成器节省内存。
使用缓存提高重复计算效率。
