# 🤖 基于 FastAPI + ChromaDB + 通义千问 RAG 智能问答系统

## 项目简介
本项目是一套轻量化端到端 RAG 私有知识库问答系统，基于 FastAPI 搭建后端接口、ChromaDB 作为本地向量数据库、阿里云通义千问提供嵌入与大模型对话能力。

实现了：私有知识库问答、多轮对话记忆、流式打字机输出、自定义伪重排检索优化，彻底解决大模型幻觉、回答重复、答非所问等常见问题。

## 技术栈
- 后端框架：FastAPI
- 向量数据库：ChromaDB（本地持久化）
- 大模型&嵌入：阿里云 DashScope 通义千问
- 开发语言：Python
- 前端页面：原生 HTML + JavaScript
- 环境配置：python-dotenv

## 核心功能
1.  私有知识库 RAG 问答
    基于本地 knowledge.txt 私有文档检索回答，不编造内容，有效缓解大模型幻觉。
2.  流式输出（打字机效果）
    处理通义千问流式完整返回问题，做增量切片输出，前端流畅不重复、不叠字。
3.  多轮会话记忆
    基于 session_id 隔离不同用户对话，自动保存上下文，支持连续追问。
4.  自定义伪重排优化
    不依赖官方 Rerank 库，通过多召回 + 文档去重 + 关键词相关性过滤，筛选最优参考片段，提升回答准确度。
5.  全局异常捕获
    统一参数校验、接口异常捕获，返回规范 JSON 格式错误信息。
6.  完整跨域配置 + 日志打印
    支持前后端跨域请求，全程日志记录请求与应答状态。

## 运行步骤
### 1. 安装依赖
pip install fastapi uvicorn chromadb dashscope python-dotenv

### 2. 配置环境变量
在 .env 文件中写入：
DASHSCOPE_API_KEY=你的阿里云密钥

### 3. 知识库初始化入库
python ingest.py

### 4. 启动后端服务
uvicorn api_app:app --reload

### 5. 前端访问
浏览器打开：
http://127.0.0.1:8000/index.html
即可进行多轮 RAG 流式对话。

## 核心流程原理
用户提问
→ 问题文本向量化
→ ChromaDB 向量相似度粗召回（一次召回5条）
→ 自定义伪重排：去重 + 关键词相关性过滤
→ 筛选最优2条参考文档
→ 拼接系统提示词 + 历史对话 + 知识库参考
→ 调用通义千问大模型
→ 流式增量处理返回前端
→ 会话结束自动保存本轮对话历史

## 项目解决的关键问题
1.  解决通义千问流式返回全量累加导致前端重复叠字问题
2.  解决多轮对话历史重复追加导致回答错乱问题
3.  解决向量检索召回内容杂乱、无关内容干扰回答问题
4.  在无官方 Rerank 库环境下，实现低成本检索精排
5.  完善异常捕获与参数校验，接口更健壮
