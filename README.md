# 🤖 基于 FastAPI + ChromaDB + 通义千问 RAG 智能问答系统
## 项目简介
本项目是一套轻量化端到端 RAG 私有知识库问答系统，基于 FastAPI 搭建后端接口、ChromaDB 作为本地向量数据库、阿里云通义千问提供嵌入与大模型对话能力，同时新增多轮对话记忆优化、问题改写等核心功能，形成全流程闭环。
核心目标：彻底解决大模型幻觉、回答重复、答非所问、上下文丢失等常见问题，实现私有知识库精准问答、流畅多轮交互，可直接用于本地部署、学习展示或二次开发。
## 技术栈
- 后端框架：FastAPI（高效异步接口，支持流式响应）
- 向量数据库：ChromaDB（本地持久化，轻量化部署，无需额外服务）
- 大模型&嵌入服务：阿里云 DashScope 通义千问（提供文本嵌入与对话能力）
- 开发语言：Python
- 前端页面：原生 HTML + JavaScript（简洁直观，支持对话交互与清空）
- 环境配置：python-dotenv（安全管理敏感信息，避免密钥泄露）
- 辅助工具：日志打印、全局异常捕获、跨域配置
## 核心功能（含新增特性）
### 基础核心功能
1.  私有知识库 RAG 问答
基于本地 knowledge 目录下的文档（含Python、Java基础及自定义知识库）检索回答，不编造内容，附带来源追溯，有效缓解大模型幻觉。
2.  流式输出（打字机效果）
处理通义千问流式完整返回，做增量切片输出，解决前端重复叠字、卡顿问题，交互更流畅。
3.  自定义伪重排优化
不依赖官方 Rerank 库，通过多召回 + 文档去重 + 关键词相关性过滤，筛选最优参考片段，提升检索与回答准确度。
4.  全局异常捕获与规范响应
统一参数校验、接口异常捕获，返回规范 JSON 格式错误信息，便于问题排查，接口更健壮。
5.  完整跨域配置 + 日志打印
支持前后端跨域请求，全程日志记录请求与应答状态，便于开发调试与问题定位。
### 新增核心功能
1.  增强版多轮对话记忆
基于 session_id 隔离不同用户对话，自动保存上下文，支持模糊指代追问（如“它有什么用？”），不丢失对话逻辑。
2.  智能问题改写
利用历史对话上下文，自动将模糊问题（如“它有什么用？”）改写为明确问题（如“基于上一轮问题：'什么是RAG？'，回答当前问题：它有什么用？”），避免检索跑偏。
3.  会话管理功能
支持对话历史清空，可随时重置会话，提升用户交互体验。

## 运行步骤（详细可落地）
### 1. 安装项目依赖
在项目根目录终端执行以下命令，安装所有所需依赖：
```bash
pip install -r requirements.txt
```
### 2. 配置环境变量
1. 在项目根目录创建 .env 文件（若已存在可直接编辑）；
2. 在 .env 文件中写入阿里云通义千问API密钥，格式如下：
```env
DASHSCOPE_API_KEY=你的阿里云通义千问API Key
```
### 3. 知识库初始化入库
将本地 knowledge 目录下的文档进行向量化处理，并存入ChromaDB，终端执行：
```bash
python ingest.py
```
### 4. 启动后端服务
启动FastAPI服务，支持热重载（修改代码无需重启服务）：
```bash
uvicorn api_app:app --reload
```
### 5. 访问前端进行对话
打开浏览器，输入以下地址，即可进入前端聊天页面，开始多轮RAG流式对话：
```
http://127.0.0.1:8000/index.html
```
⚠️  若出现“URL拼写可能存在错误，请检查”报错：
1. 确认后端服务已成功启动（终端无报错）；
2. 检查浏览器地址栏URL是否正确，确保无多余空格、字符；
3. 重启后端服务，刷新浏览器重试。
## 核心流程原理（含新增逻辑）
```
用户提问 → 对话记忆读取（若有历史对话）→ 智能问题改写（模糊问题转明确问题）
→ 问题文本向量化 → ChromaDB 向量相似度粗召回（一次召回5条）
→ 自定义伪重排（去重 + 关键词相关性过滤）→ 筛选最优2条参考文档
→ 拼接系统提示词 + 历史对话 + 知识库参考片段 → 调用通义千问大模型
→ 流式增量处理返回前端（打字机效果）→ 自动保存本轮对话历史
```
## 项目解决的关键问题
1.  解决通义千问流式返回全量累加导致前端重复叠字、卡顿问题；
2.  解决多轮对话历史重复追加、上下文丢失，导致回答错乱、指代不明问题；
3.  解决模糊问题（如“它有什么用？”）检索跑偏，导致答非所问的问题；
4.  解决向量检索召回内容杂乱、无关内容干扰，提升回答准确度；
5.  在无官方 Rerank 库环境下，实现低成本检索精排，降低部署门槛；
6.  完善异常捕获与参数校验，避免接口崩溃，提升系统稳定性；
7.  安全管理API密钥，避免敏感信息泄露，同时忽略冗余文件，保持仓库整洁。
